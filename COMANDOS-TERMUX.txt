BIBLIOTECA DA TIPOLOGIA — REFRESH 27/09/2026

1) Deixe biblioteca-da-tipologia-refresh-termux.zip em Downloads.

2) Antes de aplicar, o repositório deve estar limpo (`git status --short` sem saída).

No Termux:

pkg update -y
pkg install -y git gh nodejs unzip rsync
termux-setup-storage
rm -rf ~/bdt-refresh
mkdir -p ~/bdt-refresh
unzip -q ~/storage/downloads/biblioteca-da-tipologia-refresh-termux.zip -d ~/bdt-refresh
bash ~/bdt-refresh/biblioteca-da-tipologia-refresh-termux/apply-refresh.sh ~/biblioteca-da-tipologia

3) Configure o Client ID WEB público usado pelo Google/Supabase:

cd ~/biblioteca-da-tipologia
gh variable set GOOGLE_WEB_CLIENT_ID --body 'SEU_WEB_CLIENT_ID.apps.googleusercontent.com' --repo elenaess/biblioteca-da-tipologia

4) Envie:

git add -A
git commit -m 'fix: refresh reader native auth and mobile UX'
git push origin main

5) Abra o Actions. O job imprime o SHA-1 do APK final. Cadastre esse SHA-1 + package br.org.bibliotecadatipologia em um OAuth Client Android no Google Cloud e rode o workflow novamente.
